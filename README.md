# 👁️ Invisibility Portal

Real-time invisibility effect using hand gesture detection and background 
subtraction. Create a portal with your hands and make things disappear!

## ✨ Features

- Real-time hand tracking via webcam
- Pinch gesture detection
- Invisible portal between both hands
- Glowing yellow portal border with corner accents
- No installation — runs in browser!

## 🚀 Live Demo

👉 [invisibility-portal.vercel.app](https://invisibility-portal.vercel.app)

## 🛠️ Tech Stack

- MediaPipe Hands
- HTML5 Canvas
- Vanilla JavaScript
- Background subtraction technique

## 📦 How to Run Locally

```bash
git clone https://github.com/im-alisher/invisibility-portal.git
cd invisibility-portal
# Open index.html in Chrome
```

## 🎮 How to Use

1. Open in Chrome and allow camera access
2. **Step away** from camera for 3 seconds (background capture)
3. Come back and show **both hands**
4. **Pinch** index finger + thumb on BOTH hands
5. A glowing portal appears — anything inside turns invisible! 👻

## ⚠️ Tips

- Use in a **well-lit room** for best results
- **Plain background** works best
- Chrome browser recommended
